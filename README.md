# Лабораторная работа № 12

* **Студент:** Пылинский Даниил Максимович
* **Группа:** ПИ 1-1
* **Тема:** Адреса и указатели

## Назначение файлов проекта

* **`main.c`** — демонстрация получения адреса переменной (`&x`), разыменования указателя (`*p`) и обмена значений двух переменных с помощью функции `swap(int *a, int *b)`.
* **`self.c`** — реализация функции `order_pair(int *a, int *b)`, которая упорядочивает два числа так, чтобы первое значение стало не больше второго (`*a <= *b`), выполняя обмен только при `*a > *b`.
* **`tests.txt`** — протокол обязательных и собственных граничных тестов с ожидаемыми и фактическими результатами.

## Ограничения и правила

* Передаваемые в функции указатели всегда ссылаются на существующие инициализированные переменные типа `int`.
* Глобальные переменные в программах не используются.

## Команды сборки (PowerShell / Bash)

```bash
gcc -std=c11 -Wall -Wextra -Wpedantic main.c -o lab12
gcc -std=c11 -Wall -Wextra -Wpedantic self.c -o self
```
